## About this repository

This repository hosts my personal portfolio — a static site with no build step or dependencies.

```
index.html              # single-page portfolio
favicon.svg             # monogram favicon
assets/css/styles.css   # design system, layout, responsive rules
assets/js/main.js       # scroll reveals, counters, filters, workflow animation
assets/img/             # logo, icons, portrait cutout
assets/docs/            # CV (PDF)
```

### Running locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

### Deployment

Live at **https://mueedmbrk.github.io/mueedmbrk/**, served by GitHub Pages from the
`gh-pages` branch. `.github/workflows/publish.yml` rebuilds that branch on every push
to the source branch, so edits go live on their own — no manual step.
